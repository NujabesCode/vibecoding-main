3. 폴더 구조, 데이터 흐름, API 목록, 테이블 목록을 코드와 맞춘다. 없는 걸 쓰지 않는다
4. "찜찜한 곳"에서 해결된 건 지우지 말고 ~~취소선~~ + 어떻게 해결했는지 한 줄
5. 새로 생긴 찜찜한 곳이 있으면 솔직하게 추가한다
